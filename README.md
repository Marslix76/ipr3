## Подготовка проекта

Создать файл `.env` из примера:

```bash
cp .env.example .env
```

## Запуск проекта

Собрать и запустить контейнеры:

```bash
docker compose up -d --build
```

Проверить состояние контейнеров:

```bash
docker compose ps
```

Остановить проект:

```bash
docker compose down
```

## Сервисы

Проект состоит из двух сервисов:

- **app** — приложение.
- **redis** — хранилище данных.

Приложение обращается к redis через внутреннюю сеть docker compose. Данные redis сохраняются в docker volume `db`.

## Ограничения и безопасность

Для приложения настроены:

- запуск от непривилегированного пользователя
- файловая система только для чтения
- ограничение памяти — 256 MiB
- ограничение CPU — 1 ядро

## Автоматическая проверка

Запустить проверочный скрипт:

```bash
./scripts/check.sh
```

Скрипт автоматически проверяет:

- начальное значение счетчика
- увеличение счётчика через POST-запросы
- сохранение данных после пересоздания приложения
- поведение приложения при остановке и запуске redis
- создание резервной копии данных redis.

После завершения проверки тестовые данные удалются.

Резервная копия создается в файле `copy` в корне проекта.
